# Bizora Master Build Specification v1.0

This repository follows the confidential Master Build Specification v1.0 (November 2026) provided as `Bizora_Master_Build_Specification_v1.0.pdf`.

Coding agents must treat that document as the product contract. Do not silently change entity semantics, tenant boundaries, financial rules, payment architecture, AI permissions, or module boundaries.

Sprint sequencing, entity list, API conventions and first-build stories are defined there.

**Current implementation status:** sprints 1 to 8 and the pre-pilot readiness sprint. What is built, what is partial, and what is not, item by item: `docs/PILOT_READINESS_STATUS.md`. Architectural decisions are recorded in `docs/adr/` (ADR-001 to ADR-045).
